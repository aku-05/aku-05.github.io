Dating App

A matchmaking web app with member profiles, ranked automatic matches and a contact reveal. My part was mainly the backend logic (sign-in check, matching, contact reveal) and the member-facing pages.

  • Backend: ASP.NET Core 9 API with Entity Framework Core and PostgreSQL on Supabase. I wrote the JWT validation that identifies the signed-in user
  • Matching: a ranked-matches endpoint that scores people by the skills each one has and wants, with age and profile details, plus the contact reveal and a Match table that tracks each user's matches
  • Access rules: free and paid members and the product manager role see different data and pages, enforced in the API and the interface
  • Front end (Vue 3 + TypeScript): I built signup with validation, profile setup with skill tags and photo upload, the matches page and the dashboard statistics. Teammates built the login page, styling and the Docker setup
  • Teamwork: five people, feature branches and pull requests with code review
